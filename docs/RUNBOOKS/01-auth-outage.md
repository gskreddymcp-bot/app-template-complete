# Runbook

## Symptoms
- Define trigger symptoms and impacted user journeys.

## Immediate Mitigation
- Protect users first (feature flag, kill switch, rate limit, maintenance mode).

## Root Cause Investigation
- Check recent deploys, dashboards, traces, and dependency status pages.

## Recovery Steps
- Apply fix, validate with smoke checks, and monitor stabilization.

## Prevention Actions
- Add guardrail test/alert and update ownership or process.
